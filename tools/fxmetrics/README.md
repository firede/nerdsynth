# 效果器指标（`nerdsynth-fxmetrics`）

给混响和合唱定一组客观指标，同样的测试信号分别让 FluidSynth（黑盒，只用它渲染出的音频）和 NerdSynth 渲染，算出指标并排比较、判定。目标是：质量指标上 NerdSynth 不比 FluidSynth 差；性格指标（混响多长、多亮、多响等）和 FluidSynth 接近。

## 安装

```sh
brew install fluid-synth   # 和差分测试台用同一个；写这套指标时用的是 2.6.1
```

`ab` 子命令另需 `GeneralUser-GS-2.0.3.sf2`，找法和差分测试台一样（`$NERDSYNTH_SOUNDFONTS`、`~/.nerdsynth/soundfonts`、`~/.nerdice/soundfonts`）。测指标本身不需要任何 SoundFont 文件。

## 用法

```sh
mise run fx-metrics                       # 全部采样率，含开销探针；报告写到 out/report.md
mise run fx-metrics -- --rates 44100      # 只测一个采样率
mise run fx-metrics -- --save before      # 另存结果到 out/results-before.tsv
mise run fx-metrics -- --compare before   # 报告里多一列"ours (before)"
mise run fx-metrics -- --no-cost          # 不跑开销探针
mise run fx-metrics -- --wav              # 把湿信号写到 out/render/<rate>/
mise run fx-metrics -- ab                 # 用 GeneralUser GS 渲染 A/B 试听对，写到 out/ab/
```

有任何判定不通过时退出码为 1，不通过的项也打印在终端。`FXMETRICS_DEBUG=1` 时额外打印各音的尾音电平、尾音的倍频程电平、高频段的衰减时间。

`out/` 不进仓库。

## 测试信号

每个采样率现做一个小 SF2（testkit），采样就是该采样率、按原音高播放，样本不经过插值：

- 单击（一个 0.9 的冲激）；
- 冲击串（每秒 40 个，循环）；
- 循环噪声（四个均匀分布相加，约 −12 dBFS）；
- 循环正弦：440、2000、8000 Hz 给合唱，110 Hz 起每四分之一音一个、共 96 个给混响（频率取整数赫兹，循环正好整周期）。

preset 0 只送混响（ReverbEffectsSend 100 %），preset 1 只送合唱。CC91、CC93 置 0，只由发生器决定发送量。每个测试各渲染一遍开效果和关效果，湿信号 = 开 − 关（干声两遍完全相同）。FluidSynth 的设置和差分测试台一样：`synth.reverb.engine=fdn`，混响、合唱参数默认，增益 1。

- 混响测试：100 ms 处一次单击（之后静默到 6 s），然后 96 个正弦依次各响 1 s，间隔 2.5 s。
- 合唱测试：22 s 冲击串，三个正弦各 8 s，最后 8 s 噪声。

## 指标

"FS"指 FluidSynth 的值。三类判定：

- **必须满足**：不管 FS 怎样，都要成立。
- **质量**：不比 FS 差，带容差。
- **性格**：接近 FS，带容差。在抽查采样率（22.05k、96k）上只报告不判定：FluidSynth 的混响延迟以帧为单位固定，换采样率就是另一台混响（22.05k 下延迟时间翻倍，起音 119 ms、RT60 1.9 s；96k 下起音 27 ms），追它的性格没有意义。质量指标在四个采样率上都判定。

### 混响

冲激响应取单击之后的湿信号，按单击高度归一。"起点"是第一个超过峰值 5 %（−26 dB）的帧。

| 指标 | 定义 | 类别与容差 |
| --- | --- | --- |
| 混合时间 | Abel–Huang 归一化回声密度（NED）：20 ms Hann 窗、每 1 ms 一个点，窗内超出一个标准差的样本比例除以高斯分布的值 erfc(1/√2)。从起点算起第一次 NED ≥ 0.95 的时刻，两声道平均 | 质量：≤ FS + max(5 ms, 10 %) |
| 后期回声密度 | 起点后 150–500 ms 的平均 NED | 质量：≥ FS − 0.03 |
| 尾音频谱粗糙度 | 起点后 100 ms 到 −40 dB（至多 1.1 s）这段尾音，先按宽带衰减率补偿成平稳，再做 Welch 功率谱（约 0.1 s 一段）；200 Hz–8 kHz 内每个频点相对其 1/3 倍频程平滑值的 dB 偏差的标准差。梳状、金属声的尾音谱上峰谷多，值大 | 质量：≤ FS + 0.3 dB |
| 音尾电平离散度 | 每个正弦松开后 150 ms 起 1 s 的尾音能量（dB），先减去对 log 频率的线性趋势（趋势是音色，由重心衡量），再取标准差。网络的模态稀、彼此相隔远时，有的音的尾巴明显比邻近的音长、响 | 质量：≤ FS + 0.5 dB |
| 音尾电平高点 | 同上去趋势后的电平，95 百分位减中位数 | 质量：≤ FS + 0.5 dB |
| 音尾起伏 | 同上每个尾音的 10 ms 能量包络（dB）对直线的残差均方根，96 个音平均：拍频、颤动 | 质量：≤ FS + 0.3 dB |
| EDC 偏差 | 各倍频程带（125 Hz–8 kHz，零相位 FFT 带通）的 Schroeder 积分曲线在 −5 到 −35 dB 之间对直线的残差均方根，各带平均 | 质量：≤ FS + 0.2 dB（各带只报告） |
| 20 ms 起伏 | 同一段里 20 ms 窗（5 ms 步）能量包络对直线的残差均方根，各带平均 | 质量：≤ FS + 0.3 dB（各带只报告） |
| 后期 IACC | 起点后 80 ms 到 −40 dB，左右声道归一化互相关在 ±1 ms 内的最大绝对值。越低越宽，但不能靠反相或左右失衡换来（见下两项和 lag 0 的相关，后者只报告） | 质量：≤ FS + 0.05 |
| 左右平衡 | 冲激响应左右能量比 | 必须：\|·\| ≤ max(1 dB, \|FS\| + 0.5 dB) |
| 结尾干净 | 湿信号里每段 ≥ 100 ms 的全零之前 10 ms 内的最大电平（没有全零段就取最后 10 ms）：尾音在哪个电平上被截断 | 必须：≤ −120 dBFS |
| RT60 | 各倍频程带 T30（EDC −5 到 −35 dB 的直线拟合）；另有宽带 T30 | 性格：各带 FS ± 25 %，宽带 ± 20 % |
| EDT | 各带 EDC 0 到 −10 dB 拟合外推到 60 dB | 性格：FS ± 35 % |
| 起音 | 单击到起点的时间 | 性格：FS ± 15 ms |
| 湿声电平 | 冲激响应总能量（dB，相对单击） | 性格：FS ± 2 dB |
| 尾音重心 | 粗糙度那段尾音（补偿后）功率谱 50 Hz–0.45·采样率的频谱重心 | 性格：FS ± 0.3 倍频程 |
| 音尾谱宽 | 600 Hz 以上的正弦，尾音频谱在 f ± (1.5 % f + 5 Hz) 内绕 f 的均方根宽度，折成音分后平均。延迟线调制得越深，尾音越"走音"、越像合唱 | 性格：FS ± 50 % |

### 合唱

| 指标 | 定义 | 类别与容差 |
| --- | --- | --- |
| 洁净度 | 每个正弦稳态 6 s 的湿信号频谱：f ± (1.5 % f + 5 Hz) 以内的能量对其外（20 Hz–0.45·采样率）的能量之比，取左右较小的。外面的是噪声、失真、插值误差、拉链声 | 质量：≥ FS − 3 dB |
| 立体声 IACC | 噪声段湿信号左右互相关 ±1 ms 内最大绝对值 | 质量：≤ FS + 0.05 |
| 不反相 | 噪声段 lag 0 的相关系数。FluidSynth 的合唱左右近乎反相（−0.94，单声道下湿声几乎抵消，见"单声道和"一项）；我们不学这个 | 必须：≥ −0.3 |
| 左右平衡 | 噪声段湿信号左右能量比 | 必须：\|·\| ≤ max(1 dB, \|FS\| + 0.5 dB) |
| 调制速率 | 冲击串的湿信号里逐个冲击找出各声部的延迟（峰值抛物线插值），按声部聚类，最强一类的延迟轨迹用 DFT 在 0.02–3 Hz 里找峰 | 性格：FS ± 35 % |
| 调制深度 | 所有冲击延迟的 99 百分位减 1 百分位 | 性格：FS ± 30 % |
| 音高偏移 | 正弦湿信号频谱在上述带内的均方根宽度 σ，峰值偏移 ≈ 1200·log2(1 + √2·σ/f) 音分 | 性格：FS ± 40 % |
| 湿声电平 | 噪声段湿信号能量相对干声 | 性格：FS ± 2 dB |
| 只报告 | 最短延迟、单声道和（湿声左右相加相对立体声的能量）、冲击串里看到的声部数、冲击串结束后的输出电平（合唱没有反馈，输出随输入在一条线长之后结束，不是截断） | — |

### 开销

`cargo test --release -p nerdsynth --lib synth::effects::cost -- --ignored --nocapture`（库里的一个 ignore 测试，只有它碰得到效果器类型），本工具会自动跑并读它的 `COST` 行：

- 每帧纳秒：44.1 kHz、2 s 噪声、64 帧一块，取 15 次里最快的；
- 空闲每帧纳秒：静默时按块调 `skip`；
- 内存：44.1 kHz 和 192 kHz 下 `new` 分配的字节数。

## 要注意的

- **音尾电平两项噪声大。** 它们取决于网络的模态正好落在哪里，一个确定的设计只给出一次"抽样"：把混响的四个调制正弦的初相换几组（设计上等价），95 百分位那一项在 ±0.4 dB 里跳。FluidSynth 自己在不同采样率下（等于换了一组延迟）从 3.5 到 5.9 dB。0.5 dB 的容差和这个噪声同一量级，单次比较的结论要看余量。
- 质量指标在抽查采样率上也判定，但 FluidSynth 在那里是另一台混响（见上），比较的含义和 44.1k、48k 不同。
- 起点、混合时间这类阈值指标对 5 %、0.95 这些阈值敏感，FluidSynth 的回声密度长得慢（后期 NED 只有 0.6–0.9），混合时间在不同采样率下跳得很大。
